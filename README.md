# 水果深加工招商台账后端服务

记录合作主体、园区、项目、洽谈、立项、里程碑和投产后的产能兑现情况，为招商团队提供可追溯的业务接口。

## 园区资源容量预约台账

针对同一园区向多家企业承诺用地、供电、污水处理能力的场景，提供可追溯的容量预约台账（接口前缀 `/api/v1/capacity-ledger`）：

- **容量池**：按园区 + 资源类型（用地/供电/污水处理）登记可用总量；
- **预约单**：按资源类型、有效期间（年月粒度，支持跨年度）和项目阶段登记，生命周期为 暂存 → 已确认 → 已释放/已转移；
- **确认**：在一笔事务内串行化校验总量与既有承诺，任一月份不足即整体回滚，响应中返回每个拒绝月份的来源承诺（预约单号、项目、阶段、金额）与剩余量；暂存不占用容量；
- **月度台账**：确认后按月份落明细账，历史月份的明细不可被后续修订/释放/转移覆盖，修订只重写当月及以后的月份；
- **释放**：支持全部释放与部分释放（可指定生效月份），项目撤回（退回「招商中」）或阶段回退时按规则自动释放未使用额度；
- **转移**：在同园区同资源内把未来月份额度过户给其他项目，可部分转移；
- **可追溯与幂等**：每个操作写事件留痕，登记/确认/释放/转移均支持幂等键，重复操作不重复入账。

## 运行约定

服务端代码位于 `app` 目录，默认使用项目目录中的 SQLite 文件保存业务数据。环境变量可以覆盖数据库位置和接口前缀，临时配置不应提交到仓库。

## 测试

在项目根目录执行：

```bash
python3 -m unittest discover -s tests -v
```

## 编译检查

在项目根目录执行：

```bash
python3 -m compileall -q app tests
```

## 启动服务

准备依赖后可执行 `uvicorn app.main:app --host 127.0.0.1 --port 8000`，根路径返回服务状态，接口文档位于 `/docs`。
