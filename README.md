# 水果深加工招商台账后端服务

记录合作主体、园区、项目、洽谈、立项、里程碑和投产后的产能兑现情况，为招商团队提供可追溯的业务接口。

## 容量预约台账

针对同一园区向多家企业承诺用地、供电、污水处理能力的场景，提供可追溯的容量预约台账（`/api/v1/capacity-ledger`）：预约按资源类型、有效期间和项目阶段登记，支持暂存、确认、释放与转移；确认在一笔事务内校验总量与既有承诺，拒绝项返回来源承诺与剩余量；项目阶段变更或撤回时按规则自动释放未使用额度；历史月份的预约封存，不被后来的修订覆盖。规则详见 [容量预约台账设计.md](容量预约台账设计.md)。

## 运行约定

服务端代码位于 `app` 目录，默认使用项目目录中的 SQLite 文件保存业务数据。环境变量可以覆盖数据库位置和接口前缀，临时配置不应提交到仓库。

## 测试

在项目根目录执行：

```bash
python3 -m unittest discover -s tests -v
```

## 编译检查

在项目根目录执行：

```bash
python3 -m compileall -q app tests
```

## 启动服务

准备依赖后可执行 `uvicorn app.main:app --host 127.0.0.1 --port 8000`，根路径返回服务状态，接口文档位于 `/docs`。
